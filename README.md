# Vue Bits

Vue Bits is a personal playground for experimenting with Vue.js. This repository contains a collection of small projects and reusable components designed to explore and demonstrate core Vue concepts in a practical, hands-on way.

## Purpose

The goal of this project is to deepen understanding of Vue.js by building focused examples that highlight specific features and patterns. Each "bit" is intentionally small and self-contained, making it easy to study, modify, and extend.

## Features Covered

This repository includes examples and experiments with:

- Reactive state using `refs`
- Watching state changes with `watch` and `watchEffect`
- Component communication via `emits`
- Derived state using `computed` properties
- Two-way binding with `v-model`
- API integration and asynchronous data handling
- DOM and user interaction through event listeners

## Technologies Used
- Vue.js
- JavaScript
- HTML
- CSS
- Vite (for development and bundling)


## Getting Started

Clone the repository:

```bash
git clone https://github.com/your-username/vue-bits.git
cd vue-bits

Install dependencies:
npm install

Run the development server:
npm run dev
```

## Usage

Browse through the different components and projects to explore how each feature is implemented. Modify and experiment freely to reinforce learning.

## Notes

- This is a learning-focused repository, not a polished library.
- Code may evolve frequently as new ideas and experiments are added.
- Some examples may overlap intentionally to show different approaches to the same problem.
